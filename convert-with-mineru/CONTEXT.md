# 术语表（Glossary）

本文件是 convert-with-mineru 手写文档管道的领域词汇表，只收录术语定义，不含实现细节。

## 转写产物

- **草稿（draft）**：MinerU Precision vlm 对源文档的首次转写结果，是后续校对与修订的基线。
- **校对稿（supplement）**：视觉角色对照页图逐页校对草稿后的产物。只修正与页图不符的转写；看不清之处以低置信标记留空，不猜测。
- **终稿（revised）**：语义修订层在校对稿上按分级修订原则处理后的产物，写入正式输出的 source.md。
- **三稿留痕**：草稿、校对稿、终稿连同报告一并保留，供人工比对与回溯的流程保障。

## 标记

- **低置信标记（low-confidence）**：视觉角色对"图像层面无法辨认"的片段打的标记，表示该处禁止猜测、留待裁决。
- **不确定标记（uncertain）**：语义修订层对"无法定夺是识别错误还是原文如此"的片段打的标记。终稿不含该标记，仅保留于报告。
- **页标记（page marker）**：校对稿与终稿中标识内容所属页码的标记行。finalize 依据它做页齐全性校验与重叠去重。

## 管道

- **手写管道（handwriting pipeline）**：以 MinerU 转写为起点、视觉校对与语义修订为增强、finalize 为收尾的手写文档转写流程。脚本只做确定性工作，识别与修订由 agent 编排层承担。
- **任务包（handwriting task package）**：prepare 阶段生成的自包含目录，含页图、草稿、TASK.md 指令与机器可读清单，是 agent 编排层的工作接口。
- **视觉角色（vision role）**：执行视觉补充识别的 agent（multimodal-looker subagent 或 omp vision role）。
- **语义修订层（revision layer）**：执行语义修订的主 agent 或任意强文本角色，不绑定具体模型。
- **批次重叠（batch overlap）**：长文档分批校对时每批重复携带上一批最后一页的机制；重叠页内容以后批为准。
- **忠实抄录（faithful transcription）**：视觉校对的总原则——不加、不改、不猜，只修正与页图不符的转写。
- **分级修订（graded revision）**：语义修订的裁决规则——明确识别错误则修，明确原文风格则留，中间地带打不确定标记留人工。
- **图片引用回填（image backfill）**：finalize 的安全网——终稿缺失的图片引用由草稿机械补录，防止转写链路丢失图片位置。
